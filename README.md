## Что это

**HyperNav** — движок для поиска путей в **произвольных N-мерных пространствах** (N ≥ 4), где:

- **Навигация начинается из 0-ядра** — единого anchor
- **Соседи через φ-jump**: `i → i + ⌊n/φ⌋`
- **Fibonacci-связи**: `i ± F_k`
- **Merkaba-γ опережение**: время важнее расстояния
- **A* / Bidirectional / MultiGoal** поиск
- **Проекция N → 3D**
